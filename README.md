# 🚆 Train Consist Management App

A Java-based application demonstrating real-world usage of the **Java Collections Framework (JCF)** through a Train Consist Management system.

This project incrementally implements multiple use cases (UCs), each focusing on a specific concept like Lists, Sets, Maps, Sorting, Searching, Streams, and Exception Handling.

---

## 📌 Project Objective

To build a modular train management system while mastering:

- Core Java Collections (List, Set, Map)
- Sorting & Comparators
- Searching Algorithms
- Streams API
- Exception Handling
- Performance Comparison

---

## 🧩 Use Cases Covered

### 🔰 Basic Operations
- **UC1** – Initialize Train and Display Consist Summary  
- **UC2** – Add Passenger Bogies to Train *(ArrayList)*  

### 🧱 Set Implementations
- **UC3** – Track Unique Bogie IDs *(HashSet)*  
- **UC4** – Maintain Ordered Bogie IDs *(TreeSet & Sorting)*  

### 🔗 Linked Collections
- **UC5** – Preserve Insertion Order of Bogies *(LinkedHashSet)*  

### 🗺️ Map Usage
- **UC6** – Map Bogie to Capacity *(HashMap)*  

### 🔄 Sorting
- **UC7** – Sort Bogies by Capacity *(Comparator)*  
- **UC16** – Sort Passenger Bogies by Capacity  
- **UC17** – Sort Bogie Names *(Arrays.sort())*  

### 🌊 Streams API
- **UC8** – Filter Passenger Bogies Using Streams  
- **UC9** – Group Bogies by Type  
- **UC10** – Count Total Seats *(reduce)*  

### 🛡️ Validation & Safety
- **UC11** – Validate Train ID & Cargo Codes  
- **UC12** – Safety Compliance Check for Goods  
- **UC14** – Handle Invalid Bogie Capacity  
- **UC15** – Safe Cargo Assignment *(try-catch)*  

### 🔍 Searching Algorithms
- **UC18** – Linear Search for Bogie ID *(Array-based)*  
- **UC19** – Binary Search for Bogie ID *(Optimized)*  
- **UC20** – Exception Handling During Search Operations  

### ⚡ Performance
- **UC13** – Performance Comparison *(Loops vs Streams)*


